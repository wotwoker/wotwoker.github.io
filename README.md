# Flowing Lantingarden

This is **Kongliu-chan**’s personal blog,    
built with [Valaxy](https://valaxy.site/) + [Yun theme](https://valaxy.site/themes/yun/),     
and deployed on GitHub Pages:  https://wotwoker.github.io/

## Overview

- Study notes: e.g. notes from some courses
- Tech notes: development environment setups and other practical summaries
- Life essays: personal thoughts and everyday reflections
- Friend links: my buddies (under construction)

## Tech Stack

- Static blog framework: Valaxy `0.26.10`
- Theme: `valaxy-theme-yun`
- Deployment: GitHub Actions auto-build & GitHub Pages
